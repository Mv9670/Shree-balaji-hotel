# Shree Balaji Hotel Website

## Included
- Original uploaded hotel logo
- Standard / Deluxe / Super Deluxe room categories
- Separate image carousels
- Room number allocation:
  - Super Deluxe: 101, 102, 103, 104, 105
  - Deluxe: 201, 202, 203, 204
  - Standard: 205, 206, 207, 208, 301, 302, 303, 304, 305, 306, 307
- Sold-out room state stored in browser localStorage
- WhatsApp booking flow to 7987510587
- Mobile responsive layout

## Room photos
Create a `rooms` folder and put your actual photos there with these names:
standard-1.jpg, standard-2.jpg, standard-3.jpg
deluxe-1.jpg, deluxe-2.jpg, deluxe-3.jpg
super-1.jpg, super-2.jpg, super-3.jpg

The website will show a placeholder until the files are uploaded.

## Deploy on Render
This is a static site. Create a GitHub repository, upload all files, then on Render create a Static Site and connect the repository. Publish directory: `.`
